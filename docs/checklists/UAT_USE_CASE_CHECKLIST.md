# Heart Check PHC: User Acceptance Testing (UAT) Use Case Verification Matrix

**Last Updated:** 2026-10-21

This document provides a fresh, comprehensive, and code-aligned User Acceptance Testing (UAT) verification matrix for the **Heart Check PHC** Queue Management and Analytics System. Every test case in this document is derived directly from the active source code—from the Patient Self-Service Kiosk to SuperAdmin Governance—without reliance on legacy documentation or outdated assumptions.

---

## 1. Document Overview & Verification Framework

### 1.1 Purpose
The purpose of this UAT verification matrix is to:
- Verify that every end-to-end user journey across all hospital workstations functions in strict accordance with the current codebase implementation.
- Validate role-based security boundaries, real-time WebSocket state synchronization, hardware printing telemetry, and system resilience.
- Provide a standardized protocol for developers, Philippine Heart Center (PHC) evaluators, clinical staff, and thesis examiners to record verified test outcomes.

### 1.2 Verification Status Legend
- `[PASS]` The test step executed successfully, and actual software behavior completely matched expected results.
- `[FAIL]` The test step did not produce the expected result, indicating a functional defect or unexpected behavior.
- `[BLCK]` The test step cannot be executed due to an upstream blocking defect or missing dependency.
- `[SKIP]` The test step was intentionally omitted for the current run with documented justification.
